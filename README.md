# RR Nuker source code

## FAQ

### How do I install it?

Run `pip install -r requirements.txt.

### How do i know this isn't a rat?

if you have a brain and can actually read python code you would know it is not a rat with the 62 lines of code.

### How do i know this is the original RR nuker and not a remake?

The original RR nuker was built in python converted to an executable by pyinstaller. using that information you can reverse engineer the original source code
